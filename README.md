# 771 VideoDL（柒柒壹视频下载 · 安卓版）

**把 B 站 / YouTube 等站点的视频下载到手机的安卓小应用，自带下载引擎，装完即用**——不依赖电脑，
不用装 Python 或任何运行库；B 站高清是音视频分离的，应用内置 ffmpeg 自动合并，下载出来是**带声音的单个文件**。
注:该软件为100%AI

当前版本：**v1.14**（2026-10-25）· 安卓 7.0 及以上（64 位手机；32 位老机型另有「兼容 32 位」包）

## 功能

- **下载视频**：粘贴链接（可一次多个，用空格或换行分隔），选好画质，点「开始下载」；
  基于 yt-dlp，支持它认得的一千多个站点（B 站、YouTube 等）。
- **抖音视频 / 图文（v1.13 新增；v1.14 视频优先）**：分享文案 / 短链 / 长链都行；视频优先 H.264
  （手机兼容性最好），没有 H.264 才用 HEVC；图文自动下载全部图片并转 JPG，
  存到「下载/<标题>_图文/」；大文件断流自动 Range 续传。
  **v1.14 修了「下载视频却得到图片」**：视频详情即使同时带图片/封面也按视频下载；
  只有 `/note/`、`/slides/` 或明确图文作品才存「_图文」；视频链接解析不到视频时明确报错，
  不再保存封面图。
  抖音首次使用可能要求在应用内完成一次滑块验证，完成后自动继续。
- **五档画质**：1080p / 720p / 480p / 最高画质 / 仅音频(m4a)。
- **分享导入**：在 B 站等应用里「分享 → 柒柒壹视频下载」，链接会自动填进输入框。
- **下载封面（B 站）**：一键只取封面图，和视频放同一个目录。
- **保存位置**：下载完成后复制到手机系统「下载」目录，文件管理器和相册都能看到；
  应用只申请联网权限，**不额外要存储权限**。「打开最近下载」一键打开刚下的文件。
- **应用内更新（v1.10 起）**：自动查新版本 → 应用内下载 → 调系统安装器覆盖安装。

## 不支持的情况（如实写明）

- **番剧（/bangumi/）没有专门适配**：普通视频已实测验证；番剧走的是另一套接口，未做专项验证。
- **未登录只能拿免登录画质**（1080p 及以下）：4K、1080P 高码率等会员画质需要登录，本版尚未做登录功能。
- 抖音如果触发风控，需要用户在应用内显示出的页面上完成一次滑块验证；完成后会自动继续。
