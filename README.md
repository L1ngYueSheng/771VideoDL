# 771 VideoDL（柒柒壹视频下载 · 安卓版）

**把 B 站 / YouTube 等站点的视频下载到手机的安卓小应用，自带下载引擎，装完即用**——不依赖电脑，
不用装 Python 或任何运行库；B 站高清是音视频分离的，应用内置 ffmpeg 自动合并，下载出来是**带声音的单个文件**。
注:该软件为100%AI

当前版本：**v1.11**（2026-10-16）· 安卓 7.0 及以上（64 位手机；32 位老机型另有「兼容 32 位」包）

**从 v1.10 起带应用内联网更新**：打开应用会自动查一次新版本（失败静默），发现新版即可在应用里下载
并调起系统安装器覆盖安装，下载记录与设置不受影响。v1.9 及更早的版本没有这个功能——需要手动装一次
v1.10 及以后的版本，之后就能应用内更新；也可以随时到 Releases 手动下载。

## 功能

- **下载视频**：粘贴链接（可一次多个，用空格或换行分隔），选好画质，点「开始下载」；
  基于 yt-dlp，支持它认得的一千多个站点（B 站、YouTube 等）。
- **五档画质**：1080p / 720p / 480p / 最高画质 / 仅音频(m4a)。
- **分享导入**：在 B 站等应用里「分享 → 柒柒壹视频下载」，链接会自动填进输入框。
- **下载封面（B 站）**：一键只取封面图，和视频放同一个目录。
- **保存位置**：下载完成后复制到手机系统「下载」目录，文件管理器和相册都能看到；
  应用只申请联网权限，**不额外要存储权限**。「打开最近下载」一键打开刚下的文件。
- **应用内更新（v1.10 起）**：自动查新版本 → 应用内下载 → 调系统安装器覆盖安装。

## 不支持的情况（如实写明）

- **抖音不支持**：抖音的网页接口只接受它自己页面 JS 签名过的请求，yt-dlp 走不了这条路
  （实测最新版 yt-dlp 带上 cookie 也一样失败，与引擎新旧无关）。抖音视频建议用抖音 App
  自带的「保存到相册」。
- **番剧（/bangumi/）没有专门适配**：普通视频已实测验证；番剧走的是另一套接口，未做专项验证。
- **未登录只能拿免登录画质**（1080p 及以下）：4K、1080P 高码率等会员画质需要登录，本版尚未做登录功能。

## 近几版做了什么

- **v1.11**（2026-10-16）：修 B 站下载失败——B 站改版导致旧下载引擎报「无法提取播放信息」；
  本版升级引擎并打了补丁，之前遇到报错的更新本版即可恢复。
- **v1.10**（2026-10-15）：应用内联网更新。
- **v1.9**（2026-09-28）：安装包从 137 MB 减到 73 MB（默认只带 64 位引擎）。
- **v1.8**（2026-09-28）：界面换成重做的 Flutter 版，旧安卓界面整套移除。
